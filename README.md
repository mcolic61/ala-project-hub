# ala-project-hub

This repository exists only to keep an old link working.

ALA OS used to be served from here as a single encrypted page. It moved on
2026-09-24 to its own address, behind a server-side sign-in gate:

  https://alaos.alexanderlavecchiaarchitect.com

`index.html` is a redirect to that address and nothing else. No application
code, no business content, no credentials.

The previous history of this repository — which contained months of encrypted
ALA OS pages — was moved to a private repository. Nothing encrypted is
published here any more, and nothing should be. If a future change would put
page content in this repo, that change is wrong.
